# OSRS Tracker

## Aluno

Enzo Pacheco Ruaro

## Descricao

O OSRS Bank Tracker e um sistema web feito em Laravel para organizar personagens do jogo Old School RuneScape, visualizar seus stats, gerenciar os itens do bank e acompanhar precos dos itens do Grand Exchange.

O sistema tem autenticacao, controle de acesso por roles, CRUD de characters, gerenciamento do bank, market com atualizacao de precos e painel adm..
